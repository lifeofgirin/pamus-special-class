# Pamus Grit 주말특강 V3

## 추가된 기능
- 관리자 사이트에서 학생 직접 등록
- CSV 파일로 학생 일괄 등록
- 학생 검색/삭제
- 달력에서 여러 날짜 선택
- 선택한 날짜에 같은 특강 한꺼번에 생성
- 이번 달 토/일 전체 선택
- 날짜 × 시간 타임테이블
- 타임테이블 블록 클릭 시 신청자 확인
- 학생 화면 날짜별 특강 정리
- 관리자 비밀번호: 2026180

## 업데이트 순서
1. Supabase SQL Editor에서 `supabase_update_v3.sql` 실행
2. GitHub 저장소 파일을 이 ZIP 내용으로 덮어쓰기
3. Commit
4. Vercel 자동 재배포 대기
